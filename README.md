# Settle a payment (Java)

Implement `SumAmounts.settle` in `src/main/java/sumamounts/SumAmounts.java`. Plan on 15 minutes. The rules are in [SPEC.md](SPEC.md).

Do not change `src/test/java/sumamounts/SumAmountsTest.java`.

## Run

From this directory:

```bash
mvn test
```

## Submit

This directory is only the Java task. Create a branch and push it. Do not change `src/test/`, `SPEC.md`, or `.github/`.

From this directory:

```bash
git checkout -b candidate/<your-name>
git add src/main/java/sumamounts/SumAmounts.java
git commit -m "Implement settlement"
git push -u origin candidate/<your-name>
```
